# AmadayGasht

Travel & Tourism Platform

## Overview

AmadayGasht is a modern travel and tourism platform designed to help users discover destinations, explore travel packages, and reserve tours through an intuitive and responsive user experience.

## Features

- Tour Reservation System
- Travel Packages
- Destination Showcase
- Responsive Design
- Modern UI/UX
- Mobile Friendly Interface

## Technologies

- HTML5
- CSS3
- JavaScript
- REST API
- Responsive Web Design

## Project Highlights

- Modern dark-themed design
- Tourism-focused user experience
- Interactive calendar and booking workflow
- Optimized for desktop and mobile devices
